# Play-my-list

나의 감정, 컨디션, 날씨, 분위기, 장르 등을 입력하면 유튜브 뮤직 기반의 데일리 플레이리스트 10곡을 추천해주는 서비스

## 프로젝트 정보
- **유형**: 웹사이트 / 도구
- **타겟 사용자**: 음악을 즐기는 20-40대, 유튜브 뮤직 사용자
- **출시 목표**: 최대한 빠르게 (ASAP)

## 핵심 기능
- 사용자의 감정·컨디션·날씨·분위기·장르 등 맥락 기반 플레이리스트 추천
- 플레이리스트 저장 및 공유 기능
- 특정 곡 추가/제외 기능
- 5-6개 설문으로 니즈 파악 후 유튜브 뮤직 연동 플레이리스트 구현

## 폴더 구조 (5개 팀)
- `planning/` — 기획 팀: 무엇을 만들 것인가
- `design/` — 디자인 팀: 어떻게 보여줄 것인가
- `cx/` — CX 팀: 누가 어떻게 사용할 것인가
- `marketing/` — 마케팅 팀: 어떻게 알릴 것인가
- `strategy/` — 전략 팀: 어떻게 지속 가능하게 만들 것인가
