# 고객 여정맵

## 여정 단계

```
인지 → 진입 → 설문 → 추천 수령 → 재생·저장·공유 → 재방문
```

---

## 단계별 상세

### 1. 인지 (Awareness)

| 항목 | 내용 |
|------|------|
| 채널 | SNS 공유 링크, 유튜브 뮤직 커뮤니티, 지인 추천 |
| 트리거 | 친구가 보낸 플레이리스트 링크 / "오늘 기분에 맞는 음악 추천해줌" 문구 |
| 감정 | 호기심, 가벼운 기대 |
| 설계 포인트 | 공유 URL 오픈 시 플레이리스트 바로 미리보기 가능 → 서비스 가치 즉시 전달 |

---

### 2. 진입 (Onboarding)

| 항목 | 내용 |
|------|------|
| 화면 | 랜딩 페이지 |
| 사용자 행동 | "지금 내 플레이리스트 만들기" CTA 클릭 |
| 감정 | 설렘, 가벼운 호기심 |
| 설계 포인트 | 로그인 없이 바로 시작 가능 → 마찰 최소화 |

---

### 3. 설문 참여 (Engagement)

| 항목 | 내용 |
|------|------|
| 화면 | 설문 1~5단계 |
| 사용자 행동 | 감정·컨디션·분위기·장르·국가 선택 |
| 감정 | 선택할수록 화면 컬러가 바뀌는 경험 → 몰입감, 재미 |
| 설계 포인트 | 감정 선택 시 액센트 컬러 즉시 변경 — 선택 행위 자체가 인터랙티브 |
| 이탈 리스크 | 5단계가 길게 느껴질 경우 → 진행 바(1/5)로 완료 임박감 제공 |

---

### 4. 추천 수령 (Value Delivery)

| 항목 | 내용 |
|------|------|
| 화면 | 로딩 → 추천 결과 |
| 사용자 행동 | 10곡 확인, 마음에 안 드는 곡 제외 |
| 감정 | 기대 → 만족 또는 "이 곡은 별로" 반응 |
| 설계 포인트 | 곡 제외 시 즉시 대체 + 취소 가능 → 제어감 제공 |

---

### 5. 재생·저장·공유 (Action)

| 항목 | 내용 |
|------|------|
| 행동 유형 | 유튜브 뮤직 바로 재생 / 저장 / 친구에게 공유 |
| 감정 | 만족, 공유 욕구 |
| 설계 포인트 | 공유 링크 = 새로운 사용자 유입 → 바이럴 루프 시작 |
| 저장 유도 | 비로그인 사용자에게 로딩 중 구글 로그인 안내 → 저장까지 자연스럽게 연결 |

---

### 6. 재방문 (Retention)

| 항목 | 내용 |
|------|------|
| 트리거 | 오늘 기분이 달라졌을 때, 운동·드라이브 등 새로운 상황 |
| 설계 포인트 | 같은 감정 조합도 랜덤 그라디언트·다른 10곡 → 매번 새로운 경험 |
| 재방문 목표 | 주 1회 이상 사용 습관 형성 |
