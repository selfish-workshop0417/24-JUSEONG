# 페르소나

사용자시나리오 6개를 기반으로 3개의 대표 페르소나를 정의함.

---

## Persona A. 바쁜 직장인 "지수" (32세)

| 항목 | 내용 |
|------|------|
| 직업 | 마케터, 서울 거주 |
| 음악 습관 | 유튜브 뮤직 구독 중, 출퇴근·점심시간에 주로 청취 |
| 목표 | 매일 다른 분위기의 음악을 빠르게 세팅하고 싶음 |
| 불편함 | 플레이리스트 고르는 시간이 아까움, 항상 같은 것만 듣게 됨 |
| 사용 패턴 | 퇴근길 지하철 탑승 전 모바일로 1~2분 내 세팅 |
| 핵심 니즈 | 빠름 + 지금 기분에 딱 맞음 |

**대표 시나리오**: 시나리오 1 (퇴근 중 직장인)

---

## Persona B. 활동적인 MZ "민준" (27세)

| 항목 | 내용 |
|------|------|
| 직업 | 프리랜서 디자이너 |
| 음악 습관 | 작업·운동·드라이브 등 상황별로 음악을 적극 활용 |
| 목표 | 상황에 맞는 음악을 찾는 시간을 줄이고 싶음 |
| 불편함 | 매번 장르·분위기 검색하는 게 번거롭고 결과도 만족스럽지 않음 |
| 사용 패턴 | 헬스장·드라이브 출발 전 빠르게 세팅, 친구에게 공유 |
| 핵심 니즈 | 상황 맞춤 + 공유 가능한 재미 |

**대표 시나리오**: 시나리오 5 (드라이브), 시나리오 6 (운동)

---

## Persona C. 감성 공유형 "하은" (24세)

| 항목 | 내용 |
|------|------|
| 직업 | 대학생 |
| 음악 습관 | SNS에서 음악 콘텐츠 자주 소비·공유, 음악으로 감정 표현 |
| 목표 | 오늘 내 기분을 담은 플레이리스트를 친구와 나누고 싶음 |
| 불편함 | 감정을 표현할 마땅한 수단이 없음, 텍스트보다 음악이 더 잘 전달됨 |
| 사용 패턴 | 주말 오후 모바일, 결과를 카카오톡·인스타그램으로 공유 |
| 핵심 니즈 | 감정 표현 + 공유 바이럴 |

**대표 시나리오**: 시나리오 3 (SNS 공유 대학생)
