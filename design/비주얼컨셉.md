# 비주얼 컨셉

## 톤 앤 매너

> "지금 이 순간, 나를 위한 음악"

- 복잡하지 않고 조용하게 집중시키는 분위기
- 화려한 그래픽보다 텍스트와 여백이 주인공
- 사용자가 설문에 몰입할 수 있도록 시각적 노이즈 최소화
- 음악의 감성을 색이 아닌 타이포그래피와 레이아웃으로 표현

## 컬러

| 역할 | 색상 | 설명 |
|------|------|------|
| 배경 | `#111111` (Near-black) | 다크 배경 — 텍스트와 액센트 컬러가 선명하게 부각 |
| 주요 텍스트 | `#F5F5F5` (Off-white) | 배경과 강한 대비, 눈에 편안한 밝기 |
| 보조 텍스트 | `#888888` (Gray) | 설명, 힌트, 비활성 상태 |
| 카드 / 서피스 | `#1E1E1E` | 배경보다 살짝 밝은 카드, 섹션 구분 |
| 구분선 / 테두리 | `#2E2E2E` | 다크 배경 위 섬세한 경계선 |
| 액센트 | **감정 선택에 따라 동적 변경** (아래 표 참조) | CTA 버튼, 선택 상태, 강조 요소 |

### 감정별 액센트 컬러 매핑

| 감정 | 컬러 | 헥스 |
|------|------|------|
| 설렘 | 코럴 핑크 | `#FF6B6B` |
| 신남 | 바이브런트 옐로 | `#FFD93D` |
| 평온함 | 소프트 그린 | `#6BCB77` |
| 집중 | 쿨 블루 | `#4D96FF` |
| 피곤함 | 뮤트 퍼플 | `#9B72CF` |
| 우울함 | 딥 인디고 | `#5C6BC0` |
| 미선택 (기본값) | 뉴트럴 화이트 | `#F5F5F5` |

> **원칙 — 단일 선택**: 해당 감정의 액센트 컬러가 설문 전체와 추천 결과 화면에 유지됨. fade transition 적용.
>
> **원칙 — 복수 선택**: 선택된 감정 컬러들을 랜덤 방향 그라디언트로 혼합 적용.
> - 방향각은 선택 시마다 무작위 생성 (0°~360°) — 같은 감정 조합이어도 매번 다른 그라디언트
> - 적용 영역: CTA 버튼 배경, 선택 상태 체크박스, 추천 결과 상단 타이틀 등 액센트 포인트
> - 배경 전체에는 그라디언트를 적용하지 않음 — Near-black 유지로 가독성 확보

## 타이포그래피

| 용도 | 스타일 | 예시 |
|------|--------|------|
| 메인 질문 | Bold, 24-28px | "오늘 나의 감정은?" |
| 선택지 텍스트 | Medium, 16-18px | "설렘", "피곤함", "평온함" |
| 보조 설명 | Regular, 13-14px | "복수 선택 가능해요" |
| 결과 곡명 | SemiBold, 15-16px | 트랙 타이틀 |
| 결과 아티스트명 | Regular, 13px | 아티스트명, 앨범명 |

- **폰트**: `Pretendard` 단일 적용 — 한국어·영문·숫자 모두 지원, 웹폰트 무료 제공 (한국어 가독성 최적화)
- **행간**: 1.6 이상 — 텍스트가 답답하지 않게

## 일러스트 / 아이콘

- 필요 최소한으로 사용 — 없어도 되는 곳엔 사용 안 함
- 사용 시 **심플한 라인 일러스트** (두께 1.5-2px, 단색)
- 적합한 위치: 랜딩 페이지 히어로 영역, 전체 미선택 시 빌보드 차트 안내 화면
- 아이콘: 선택지 앞 소형 아이콘 (감정·분위기 직관적 표현용), Lucide Icons 또는 동일 계열 라인 아이콘셋 사용
