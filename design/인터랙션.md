# 핵심 인터랙션

## I-01. 설문 선택 (감정: 칩 / 나머지: 체크박스)

| 항목 | 내용 |
|------|------|
| 감정 기본 상태 | 테두리 선 (`#2E2E2E`), 배경 `#1E1E1E`, 텍스트 Off-white |
| 감정 선택 상태 (단일) | 테두리·배경 해당 감정 액센트 컬러 (10% 투명도), 텍스트 Bold + 화면 액센트 fade 전환 |
| 감정 선택 상태 (복수) | 선택된 컬러들을 랜덤 방향 그라디언트로 혼합 — 선택 추가/해제 시마다 새 방향각으로 재생성 |
| 체크박스 기본 상태 | 빈 사각형 테두리 (`#2E2E2E`) |
| 체크박스 선택 상태 | 액센트 컬러 채움 + 체크 아이콘 |
| 전환 | 탭 즉시 반응 — 딜레이 없이 |
| 복수 선택 | 선택된 항목 여러 개 동시 활성화 유지 |

## I-02. 컨디션 슬라이더

| 항목 | 내용 |
|------|------|
| 입력 방식 | 드래그 또는 탭으로 1~10 선택 |
| 피드백 | 선택 값 슬라이더 위에 숫자로 표시 |
| 모바일 최적화 | 터치 영역 충분히 확보 (thumb 크기 44px 이상) |

## I-03. 설문 단계 전환

| 항목 | 내용 |
|------|------|
| 전환 방식 | 슬라이드 (오른쪽 → 왼쪽) 또는 페이드 |
| 뒤로 가기 | 상단 "←" 버튼으로 이전 단계 복귀, 선택값 유지 |
| 진행 표시 | 상단 도트(●○○○○) 또는 얇은 프로그레스 바 |

---

## I-04. 곡 제외 (✕ 버튼)

| 항목 | 내용 |
|------|------|
| 동작 | ✕ 탭 → 해당 곡 슬라이드 아웃 → 대체 곡 슬라이드 인 |
| 애니메이션 | 제거: 좌측 슬라이드 아웃 / 추가: 하단에서 페이드 인 |
| 피드백 | 토스트 메시지: "다른 곡으로 교체했어요" + **"제외 취소"** 버튼 (3초 유지) |
| 제외 취소 동작 | "제외 취소" 탭 → 대체 곡 제거 + 원래 곡 복원 (슬라이드 인) → 토스트 닫힘 |
| 취소 만료 | 3초 내 미탭 시 토스트 자동 닫힘, 이후 되돌리기 불가 |

## I-05. CTA 버튼 — 유튜브 뮤직 재생

| 항목 | 내용 |
|------|------|
| 위치 | 추천 결과 하단 고정 (sticky) |
| 동작 | 탭 → 유튜브 뮤직 앱으로 딥링크 또는 브라우저 이동 |
| 상태 | 로딩 중: 버튼 비활성화 + 스피너 표시 |

## I-06. 저장 / 공유 피드백

| 항목 | 내용 |
|------|------|
| 저장 성공 | "유튜브 뮤직에 저장됐어요 ✓" 토스트 (초록, 2초) |
| 공유 링크 복사 | "링크가 복사됐어요 ✓" 토스트 (2초) |
| 로그인 유도 위치 | 로딩 화면 하단 비차단형 안내 (OAuth 팝업 방식 전제) |
| 로그인 필요 시 (결과 화면) | 팝업 미지원 환경 fallback — Bottom sheet로 구글 로그인 유도 |
