# 화면 흐름 (Mobile-First)

## 전체 흐름 요약

```
랜딩 → 설문 (5단계) → 로딩 → 추천 결과 → 저장 / 공유
```

---

## Screen 1. 랜딩

- **구성**: 서비스명(Play-my-list) + 한 줄 소개 + 시작 CTA 버튼
- **레이아웃**: 중앙 정렬, 상하 여백 충분히
- 선택적으로 심플한 라인 일러스트 1개 배치 (헤드폰 또는 음표)
- CTA 버튼: "지금 내 플레이리스트 만들기" — 액센트 컬러 적용

---

## Screen 2-1. 설문 — 감정

- 상단: 진행 표시 (1/5 도트 또는 바)
- 질문 텍스트: "오늘 나의 감정은?" (Bold, 크게)
- 선택지: 칩(Chip) 형태 — 가로 2열 또는 wrap 배치
  - 예: 설렘 / 피곤함 / 평온함 / 신남 / 우울함 / 집중 등
- 감정 선택 즉시 화면 전체 액센트 컬러 변경 (fade transition)
- 복수 선택 가능 안내 문구 표시
- 하단: "다음" 버튼 (선택 없어도 활성화 — 건너뛰기 가능)

---

## Screen 2-2. 설문 — 컨디션

- 질문 텍스트: "오늘 나의 컨디션은?"
- 입력 방식: 1~10 슬라이더 또는 숫자 탭 선택
  - 왼쪽 레이블: "많이 지쳐있어요" / 오른쪽: "최상이에요"
- 1개만 선택 가능
- 하단: "다음" 버튼

---

## Screen 2-3. 설문 — 분위기

- 질문 텍스트: "오늘 원하는 분위기는?"
- 선택지: 체크박스 형태, 복수 선택 가능
  - 예: 차분한 / 신나는 / 감성적인 / 집중되는 / 드라이브 / 격렬한 등

---

## Screen 2-4. 설문 — 음악 장르

- 질문 텍스트: "좋아하는 음악 장르는?"
- 선택지: 체크박스 형태, 복수 선택 가능
  - 예: K-Pop / 팝 / 힙합 / R&B / 인디 / EDM / 재즈 / 클래식 / 인스트루멘탈

---

## Screen 2-5. 설문 — 국가

- 질문 텍스트: "어느 나라 음악을 들을까요?"
- 선택지: 체크박스 형태, 복수 선택 가능
  - 예: 한국 / 일본 / 미국 / 유럽 / 기타
- 하단: "플레이리스트 만들기" 버튼 (CTA, 액센트 컬러)

---

## Screen 3. 로딩

- 짧은 로딩 화면 (추천 API 호출 중)
- 텍스트: "지금 딱 맞는 음악을 고르고 있어요…"
- 애니메이션: 심플한 점 3개 페이드 또는 라인 일러스트 루프
- **구글 로그인 유도 (비로그인 사용자)**: 로딩 대기 시간을 활용해 화면 하단에 비차단형 안내 표시
  - 문구: "저장하려면 구글 계정이 필요해요. 지금 연결해둘까요?"
  - 버튼: "구글로 로그인" / "나중에"
  - 조건: OAuth 팝업 방식 사용 시 현재 페이지를 벗어나지 않으므로 로딩 흐름 유지 가능
  - 주의: OAuth redirect 방식(팝업 미지원 환경)에서는 페이지 이탈 위험 — 이 경우 로딩 화면이 아닌 결과 화면 이후로 유도 위치 변경

---

## Screen 4. 추천 결과

- 상단: "오늘의 플레이리스트" 타이틀
- 곡 목록: 카드 리스트 형태 (앨범 커버 썸네일 + 곡명 + 아티스트명 + 유튜브 뮤직 연결 아이콘)
- 개별 곡 우측: ✕ 버튼 (제외 시 대체 곡 자동 추가)
- 하단 고정 액션 바:
  - "유튜브 뮤직에서 재생" (메인 CTA)
  - "저장" / "공유" 버튼

---

## Screen 5. 저장 / 공유

- **저장**: 구글 로그인 완료 상태 → 유튜브 뮤직 계정에 플레이리스트 추가 완료 토스트 메시지
- **공유**: 고유 URL 복사 완료 토스트 메시지
