# 채널 전략 & 런칭 타임라인

## 채널별 전략

### 1. 공유 링크 (핵심 채널)
- 플레이리스트 공유 URL이 곧 광고 소재
- OG 태그로 링크 미리보기에 플레이리스트명·감정·컬러 표시 (v1.2)
- 카카오톡·인스타그램·X 공유 버튼 제공

### 2. 인스타그램
- 감정별 컬러 그라디언트 스크린샷 → 스토리 공유 유도
- "오늘 나의 플레이리스트" 해시태그 캠페인 (#오늘내플리 등)
- 릴스: 설문 → 컬러 변화 → 결과 과정 15초 영상

### 3. X (트위터)
- "오늘 감정: 설렘+피곤함 → 이런 플리가 나왔다" 텍스트+스크린샷 포맷
- 음악 추천 관련 트윗에 자연스럽게 서비스 언급

### 4. 커뮤니티
- 유튜브 뮤직 관련 카페·채널 (진성 후기 형태)
- 음악 취향 공유 오픈카톡, 디스코드 서버

## 런칭 타임라인

### D-14 ~ D-7 (출시 2주 전)
- [ ] 베타 테스터 10명 모집 (지인 기반)
- [ ] 베타 피드백 반영, 치명적 버그 수정
- [ ] SNS 계정 개설 (인스타그램, X)
- [ ] 티저 게시: "곧 출시됩니다" + 감정 컬러 이미지

### D-7 ~ D-1 (출시 1주 전)
- [ ] 공유용 플레이리스트 샘플 10개 미리 생성
- [ ] 커뮤니티 사전 알림 게시
- [ ] 팀원 각자 SNS에 개인 플레이리스트 공유 (자연스러운 바이럴 시작)

### D-Day (출시)
- [ ] 전체 채널 동시 게시
- [ ] "오늘 내 감정 플리 만들어봤어요" 포맷으로 팀 SNS 일제 공유
- [ ] 커뮤니티 런칭 게시글

### D+1 ~ D+7 (출시 후 1주)
- [ ] 공유 링크 유입 경로 분석
- [ ] 이탈 구간 파악 (설문 어느 단계에서 나가는지)
- [ ] 유저 피드백 수집 (구글 폼 또는 인앱 피드백)
- [ ] 빠르게 수정 가능한 버그·UX 이슈 즉시 반영
