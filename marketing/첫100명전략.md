# 첫 100명 사용자 확보 전략

## 핵심 전제

> 별도 광고 예산 없이, **공유 기능 자체가 첫 번째 마케팅 채널**

플레이리스트 공유 링크를 받은 사람이 서비스를 처음 접하는 구조 — 링크 미리보기에서 가치를 즉시 전달하는 것이 핵심.

---

## 단계별 전략

### Step 1. 소셜 시딩 (0~2주)
- 팀·지인 네트워크에서 직접 사용 후 공유 링크 SNS 게시
- 인스타그램 스토리 / X(트위터)에 "오늘 내 기분 플레이리스트" 형식으로 자연스럽게 노출
- 감정별 컬러 그라디언트 UI 스크린샷이 공유 콘텐츠로 자연 바이럴 유도

### Step 2. 커뮤니티 직접 접근 (2~4주)
- 유튜브 뮤직 관련 커뮤니티 (레딧 r/youtubemusic, 유튜브 뮤직 카페, 디시인사이드 음악 갤러리)
- "이런 서비스 써봤어요" 형식의 진성 후기 게시 — 광고성 X, 경험 공유 형태
- 음악 관련 오픈카톡 채널, 플레이리스트 공유 채널에 링크 배포

### Step 3. 바이럴 루프 가동 (4주~)
- 공유된 링크를 통해 신규 유입 → 본인도 설문 → 새로운 공유 링크 생성
- 공유 링크 유입 사용자 비율 추적 → 바이럴 계수(K-factor) 측정
- 목표: 사용자 1명이 평균 1.2명 이상 신규 유입 유도

## 목표 지표

| 지표 | 목표 |
|------|------|
| 출시 2주 내 가입 | 100명 |
| 설문 완료율 | 60% 이상 |
| 공유 링크 생성율 | 방문자의 20% 이상 |
| 공유 링크 통한 신규 유입 비율 | 30% 이상 |
