# MVP 범위

## MVP 정의

> **핵심 플로우**: 설문 → 추천 → 유튜브 뮤직 연동

MVP는 "오늘 나에게 맞는 10곡을 빠르게 받아 유튜브 뮤직에서 재생한다"는 단 하나의 경험을 완성하는 데 집중한다.

---

## 포함 (MVP 필수)

| 기능 | 이유 |
|------|------|
| 맥락 설문 (5-6단계) | 서비스의 핵심 진입점 |
| 플레이리스트 10곡 추천 | 서비스의 핵심 가치 |
| 유튜브 뮤직 연동 링크 | 실제 재생까지 이어져야 완결 |
| 곡 제외(커스터마이징) | 추천 결과에 대한 최소한의 제어권 |
| 로컬 저장 (localStorage) | 비로그인 fallback |
| 링크 공유 (URL 복사) | 바이럴 루프의 시작점 |
| 구글 OAuth 로그인 | 유튜브 뮤직 계정 연동 저장의 전제 조건 |

## MVP 완료 기준

- [ ] 설문 5단계 이상 완료 시 추천 결과 화면 노출
- [ ] 추천 결과에서 유튜브 뮤직 링크 클릭 시 해당 곡 재생 확인
- [ ] 곡 제외 버튼 동작 및 대체 곡 표시 확인
- [ ] 결과 URL 공유 시 동일 플레이리스트 재현 확인
- [ ] 모바일 브라우저에서 전체 플로우 정상 동작 확인
