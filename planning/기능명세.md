# 기능 명세

## F-01. 맥락 설문

| 항목 | 내용 |
|------|------|
| 설명 | 사용자로부터 현재 상태 정보를 수집하는 5단계 설문 |
| 입력 항목 | 오늘 나의 감정 / 오늘 나의 컨디션 / 오늘 내가 원하는 분위기 / 내가 선호하는 음악 장르 / 국가 선택 |
| 선택 방식 | 감정·분위기·음악 장르·국가: 중복 선택 가능 / 컨디션: 1~10 척도에서 1개만 선택 |
| 필수 여부 | 모든 항목 선택 사항 — 미선택 항목은 추천 조건에서 제외 |
| 전체 미선택 | 모든 항목 미선택 시 빌보드 차트 순위 기준으로 추천 목록 작성 |
| 국가 선택지 예시 | 한국, 일본, 미국, 유럽 등 (추후 확장 가능) |

## F-02. 플레이리스트 자동 추천

| 항목 | 내용 |
|------|------|
| 설명 | 설문 결과를 바탕으로 유튜브 뮤직 기반 10곡 추천 |
| 출력 | 곡명, 아티스트, 앨범 커버, 유튜브 뮤직 링크 |
| 동작 | 설문 완료 → 추천 결과 화면 자동 전환 |
| 제약 | 유튜브 뮤직 API 응답 기준, 재생 가능 곡만 표시 |

---

## F-03. 플레이리스트 저장

| 항목 | 내용 |
|------|------|
| 설명 | 추천받은 플레이리스트를 유튜브 뮤직 계정에 저장 |
| 로그인 방식 | 구글 OAuth — 유튜브 뮤직 대상 서비스이므로 구글 계정 연동 |
| 동작 | 구글 로그인 → '저장' 버튼 클릭 → 유튜브 뮤직 계정에 플레이리스트 직접 추가 |
| 비로그인 시 | 로컬 저장(localStorage)으로 fallback — 기기 내에서만 유지 |
| 기술 조건 | YouTube Data API v3의 `playlists.insert` 사용, OAuth 2.0 scope: `youtube` 또는 `youtube.force-ssl` 필요 |

## F-04. 플레이리스트 공유

| 항목 | 내용 |
|------|------|
| 설명 | 생성된 플레이리스트를 링크 또는 SNS로 공유 |
| 동작 | '공유' 버튼 클릭 → 고유 URL 생성 또는 클립보드 복사 |
| 채널 | 링크 복사, 카카오톡, 인스타그램, X(트위터) |
| 추후 | OG 태그 기반 미리보기 이미지 자동 생성 |
