## 시나리오 1. 퇴근 중 음악 고르기 귀찮은 직장인

| 항목 | 내용 |
|------|------|
| **Who** | 32세 직장인, 유튜브 뮤직 구독 중, 매일 퇴근길에 음악 청취 |
| **When** | 퇴근길 지하철 탑승 직전 (오후 7시) |
| **Where** | 모바일 브라우저 |

**기대 결과**: 설문 완료 후 30초 이내에 나에게 맞는 플레이리스트 확인 및 재생 시작

**기대 결과**: 저장된 플레이리스트로 다음에도 같은 분위기 재현 가능

## 시나리오 5. 친구들과 드라이브 중인 사용자

| 항목 | 내용 |
|------|------|
| **Who** | 28세 직장인, 주말에 친구 3명과 드라이브 정기적으로 즐김 |
| **When** | 드라이브 출발 직전 또는 음악이 끊겼을 때 |
| **Where** | 모바일 (동승자가 조작) |
| **Why** | 드라이브 분위기에 맞는 음악을 빠르게 틀고 싶고, 혼자가 아니라 다 같이 즐길 수 있는 선곡이 필요 |
| **How** | 분위기(신남·드라이브), 장르(팝·EDM), 국가(미국·유럽) 선택 → 10곡 추천 → 유튜브 뮤직 재생 → 공유 링크로 다른 친구에게도 전송 |

**기대 결과**: 드라이브 내내 끊김 없이 분위기에 맞는 음악 재생, 친구들도 같은 리스트 공유 가능
