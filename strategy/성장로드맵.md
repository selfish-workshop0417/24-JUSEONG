# 성장 로드맵

## 핵심 지표 (North Star Metric)

> **주간 활성 사용자(WAU) 중 플레이리스트를 저장하거나 공유한 비율**

단순 방문이 아닌 "음악을 실제로 들었고 다시 오고 싶은 경험"을 한 사용자 비율을 핵심으로 삼음.

---

## Phase 1 — MVP 출시 (0~3개월)

| 목표 | 내용 |
|------|------|
| 제품 | 설문→추천→유튜브 뮤직 연동 핵심 플로우 완성 |
| 사용자 | MAU 1,000명 달성 |
| 지표 | 설문 완료율 60% 이상, 공유 클릭율 15% 이상 |
| 운영 | 전면 무료, 사용 데이터 수집 |

---

## Phase 2 — 유지 및 개선 (3~6개월)

| 목표 | 내용 |
|------|------|
| 제품 | 계정 로그인·히스토리·SNS 공유 추가 (v1.1) |
| 사용자 | MAU 5,000명, 재방문율 30% 이상 |
| 지표 | 저장 3개 초과 사용자 비율 모니터링 |
| 수익 | 얼리버드 프리미엄 전환 시작 |

---

## Phase 3 — 성장 (6~12개월)

| 목표 | 내용 |
|------|------|
| 제품 | 고급 필터·곡 직접 추가·OG 이미지 (v1.2) |
| 사용자 | MAU 20,000명, 유료 전환율 5% 이상 |
| 지표 | 월간 공유 링크 발생 수, 신규 유입 중 공유 링크 유입 비율 |
| 파트너십 | 음악 커뮤니티·유튜버 협업 1건 이상 |

---

## Phase 4 — 수익화 안정 (1년 이후)

| 목표 | 내용 |
|------|------|
| 제품 | 프리미엄 구독 정식 운영 (v2.0) |
| 사용자 | MAU 50,000명, 유료 사용자 2,500명 (전환율 5%) |
| 수익 | 월 구독 기준 약 ₩725만/월 (2,500 × ₩2,900) |
| 확장 | 드라이브·피트니스 파트너십 연동 검토 |
