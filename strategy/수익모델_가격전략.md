# 수익 모델 & 가격 전략

## 기본 방향

> 초기 유저베이스 확보 → 무료 경험으로 락인 → 프리미엄 전환

유튜브 뮤직 연동 특성상 사용자는 이미 구글 계정을 보유. 로그인 장벽이 낮아 초기 무료 유입에 유리함.

---

## 티어 구조

| 기능 | 무료 (Free) | 프리미엄 (Premium) |
|------|------------|------------------|
| 맥락 설문 + 추천 | ✓ 무제한 | ✓ 무제한 |
| 유튜브 뮤직 연동 재생 | ✓ | ✓ |
| 곡 제외 커스터마이징 | ✓ | ✓ |
| URL 공유 | ✓ | ✓ |
| 플레이리스트 저장 | 최근 3개 | 무제한 |
| 히스토리 조회 | X | ✓ (날짜별 조회) |
| 고급 필터 | X | ✓ (BPM, 발매연도 등) |
| 광고 | 추후 검토 | 없음 |

> **무료 저장 3개 제한**이 핵심 전환 유도 장치 — 자주 쓸수록 프리미엄 필요성을 자연스럽게 체감

---

## 가격 전략

| 플랜 | 가격 | 비고 |
|------|------|------|
| 무료 | ₩0 | 영구 무료 티어 유지 |
| 프리미엄 월간 | ₩2,900 / 월 | 커피 한 잔 이하 심리적 저항선 |
| 프리미엄 연간 | ₩24,000 / 년 | 월간 대비 약 30% 할인 (₩2,000/월) |

> **근거**: 유튜브 뮤직 구독료(₩8,690/월)보다 훨씬 낮은 보조 서비스 포지셔닝. 연간 플랜으로 장기 유지율 확보.

---

## 전환 시점

- MVP 출시 후 **3개월간 전면 무료** 운영 → 사용 패턴 데이터 수집
- 저장 3개 초과 사용자 비율이 20% 이상 도달 시 프리미엄 전환 시작
- 프리미엄 도입 전 기존 사용자에게 **얼리버드 1개월 무료** 제공
