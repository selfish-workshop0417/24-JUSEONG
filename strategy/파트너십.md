# 잠재 파트너십

## 핵심 파트너 (필수)

### YouTube Music / Google
- **관계**: 기술 의존 파트너 — YouTube Data API v3 기반 플레이리스트 연동
- **리스크**: API 정책 변경 또는 사용량 제한 시 서비스 영향 직접적
- **대응**: API 할당량 모니터링, 캐싱 전략으로 호출 최소화

---

## 성장 단계 파트너십 (v1.x 이후)

### 음악 커뮤니티 / 미디어
| 파트너 유형 | 예시 | 협력 방식 |
|------------|------|---------|
| 음악 유튜버 / 스트리머 | 플레이리스트 큐레이터 채널 | 콜라보 플레이리스트 기획, 공동 홍보 |
| 음악 버티컬 미디어 | 이즘(IZM), 멜로망스 팬카페 등 | 콘텐츠 제휴, 배너 교환 |
| 감성 SNS 계정 | 인스타그램 음악 계정 | 플레이리스트 공유 콘텐츠 협업 |

### 라이프스타일 브랜드 (v2.0 이후)
| 파트너 유형 | 예시 | 협력 방식 |
|------------|------|---------|
| 카페 / 공간 브랜드 | 감성 카페 체인 | "이 공간의 플레이리스트" 공동 기획 |
| 피트니스 앱 | 운동 추적 앱 | 운동 강도 연동 플레이리스트 추천 |
| 드라이브 / 모빌리티 | 카셰어링 서비스 | 차량 내 플레이리스트 연동 |

> 드라이브·운동 시나리오(사용자시나리오 5·6번)가 파트너십 방향의 근거가 됨
